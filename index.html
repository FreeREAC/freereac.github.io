FreeREAC package repository

The first FreeREAC package repository: signed RPMs of libreac and reac-pw up to the versions it already carries. New releases of the REAC stack and the OpenMixer console are published in the OpenMixer channel; install openmixer-release from there instead of adding this repository.

sudo dnf install https://www.openmixer.org/rpm/openmixer-release.noarch.rpm
sudo dnf install reac-pw

Repository metadata and every package are GPG-signed. See the repository for details.
