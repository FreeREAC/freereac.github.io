FreeREAC package repository

Signed RPMs for the openmixer console and the REAC transport stack.

sudo dnf config-manager addrepo --from-repofile=https://freereac.github.io/rpm/freereac.repo
sudo rpm --import https://freereac.github.io/rpm/RPM-GPG-KEY-freereac
sudo dnf install openmixer-full

mod-host is the LV2 plugin host openmixer-server spawns for channel inserts. No Fedora or RPM Fusion repository carries it, which is why this one does: without it dnf install openmixer-full has nothing to resolve the console's plugin host against. Debug information ships alongside as mod-host-debuginfo and mod-host-debugsource; sources for every package are in the freereac-source repository, disabled by default.

Repository metadata and every package are GPG-signed. See the repository for details.
